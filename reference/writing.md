# 書き方（見出し・文・数字・色）

## 見出し（h1）

- **このページの結論を1文で言い切る**。見出しだけを順に読むと、話の筋と価値が分かるようにする
- 題名（「市場規模」「サービス概要」「1枚で説明」）にしない
  - ✗ 市場規模 → ✓ 最初の5つの国・地域だけで、3年目に年1,000億円の需要がある
  - ✗ 収益モデル → ✓ 1箱5,000円のうち、農家に1,100円、自社に687円が残る
- 数字を1つ入れると強い（`data-f` で埋め込む）
- 1行に収める（doc は全角で約 38 字、pitch は約 20 字）。2行になるならページの言いたいことが2つある
- 口語・曖昧な言葉（「壁」「割る」「手を打ってある」「うまくいく」）と、根拠のない一般化（「海外では」「証明済み」）を使わない
- 英語のデッキ：文ではなく主張の短い句（`Revenue hits ¥2.1B in year 3`）。先頭だけ大文字

## 1ページ1メッセージ

- 本文は見出しを支える材料だけにする。支えない情報は付録か別ページへ
- 強調（`.key`・`<b>`・`highlight`）は1ページに1〜2か所
- 帯（`.strip`）は「だから何か」を言い直す1〜2文。本文の繰り返しにしない
- 注・出典・前提は foot に。本文に括弧書きを増やさない

## 文

- 1文 40 字くらいまで。箇条書きは1項目1行、多くて5項目
- 主語と数字を具体的に：「多くの人が」ではなく「会員の42%が」
- 同じものは同じ言葉で呼ぶ（途中で呼び名を変えない）。略語は最初に正式名
- 決まっていないことは「未定」と書き、選択肢を並べる（`.card.open` と `.tag`）。決まっていないことを決まったように書かない

## 数字

- 手で打たず計算の結果を埋め込む（[data.md](data.md)）
- 単位を1ページでそろえる（億円・万人）。桁区切りを入れる
- 予測・仮の値は foot に書く（「数字は calc.py の仮の値」「平均の予測」）
- 為替は foot に「1ドル=150円」

## 色

- 使う色は2色＋灰色：**強調色（accent）**＝伝えたいこと・自社・良い／**注意色（warn）**＝お金・費用・リスク・未定
- 同じ意味には同じ色（全ページで）。グラフの強調も同じ強調色
- 色だけで区別しない（ラベル・線の形・破線も使う）

## 文字の大きさ（`?check` が調べる）

| | doc（読む資料） | pitch（映す発表） |
|---|---|---|
| いちばん小さい文字 | 16px | 54px |
| 見出し | 46px | 80px |
| 本文 | 22〜24px | 60px 以上 |

## 日本語と英語

- `<html lang="ja">` は Noto Sans JP、`lang="en"` は Inter が先に立つ。見出しの約物は詰める（palt）
- 日本語の見出しの句読点：「、」はよいが「。」は付けない（2文にするときだけ間に「。」）
- 英語と日本語を混ぜるとき、kicker（小見出し）は英語の大文字、見出しと本文は日本語

## ページの順番

1. 表紙（題＝価値の言い切り、要約、目次）
2. 章ごとに中扉 → 結論のページ → 根拠のページ
3. 最後にリスク・次の行動・お願い
4. 付録は本編で出てくる順に（本編の foot から `a.ref` でリンク）
